# Rika Translator（梨花翻译工具）0.7.4 使用说明

适用于 Windows 10/11 x64。程序自带 .NET 运行时，需要 Microsoft Edge WebView2 Runtime。

## 开始使用

1. 将完整程序目录放到有写入权限的位置，双击 `RikaTranslator.exe`。
2. 在“AI 翻译”中添加自己的 OpenAI 兼容服务，填写地址和 API Key。
3. 点击“获取模型”后选择模型，也可以手动填写模型 ID；保存服务并主动测试连接。
4. 添加游戏实际使用的 EXE 或游戏目录，查看引擎识别、适配能力和安装计划。
5. 安装或卸载适配前关闭游戏。安装后运行游戏，并保持本工具运行。
6. 在游戏详情设置原文语言、目标语言、上下文、字体和译文；通过日志排查问题。

请整体保留 `runtime`、`wwwroot`、`adapters` 和 `licenses` 等目录。程序不是单文件应用。
首次运行会在程序旁创建自己的 `data`，分发文件不包含预设服务或个人 API Key。

## 翻译服务

支持 OpenAI 兼容 Chat Completions，基础地址和完整端点均可配置；支持 JSON 和 SSE 返回。
“测试连接”会向所选服务发送一次实际翻译请求，可能产生服务费用。
游戏原文及配置的上下文会发送给你选择的服务，请自行了解该服务的数据处理方式。

## 引擎适配

| 引擎 | 提供的适配路线 | 使用范围 |
| --- | --- | --- |
| Unity Mono | BepInEx 5 + XUnity.AutoTranslator | 自定义控件、TMP 和已有插件需逐款确认 |
| Unity IL2CPP x86/x64 | 匹配的 BepInEx 6 和 XUnity IL2CPP | 首次生成 interop 可能下载 Unity 基础库；版本兼容需确认 |
| Ren’Py 7/8 | 独立实时翻译插件 | 动态文字和布局需逐款确认 |
| RPG Maker MV/MZ | JavaScript 翻译插件 | 图片按钮、自定义插件和复杂窗口可能不覆盖 |
| Unreal UE 5.7 Win64 | 固定版本 UE4SS + Lua 本地桥接 | 主要处理受支持的 UMG 文本；其他版本尚未开放同等适配 |
| Galgame / Windows x86/x64 文本 Hook | LunaHook 取词、翻译浮窗及可回填通道的内嵌 | 通道、编码、绘字和内嵌能力以具体游戏为准 |

引擎识别、取得文本、回传译文和最终画面是不同阶段。适配路线不保证所有游戏和文字控件可用。
不提供 OCR，图片或视频中无法直接提取的文字暂不覆盖。
公开分发目录不包含开发用截图和游戏验证记录，游戏详情不会提供这批内部记录。

## Galgame 浮窗与内嵌

启动游戏后，在游戏详情连接对应进程，选择实际对白通道。角色名、逐字输出和系统消息可能是不同通道。
先检查浮窗译文；通道标为“可内嵌”时，可开启内嵌并设置等待时间。
译文未及时返回时，游戏继续显示原文，迟到的译文仍可进入浮窗和缓存。

浮窗支持透明背景、移动、缩放、滚动、原文显示、字体颜色和鼠标穿透。
鼠标穿透恢复快捷键优先使用 `Ctrl+Alt+T`，被占用时尝试 `Ctrl+Alt+F8`；两者均不可用时禁用穿透。
浮窗字号与内嵌比例独立。内嵌比例为 50–200%，100% 以游戏原字体为基准。
字体颜色设置作用于浮窗，游戏内嵌文字不提供同等颜色设置。

修改字体或内嵌字号后，BGI 等会缓存字形的游戏需要保存进度、完全退出并重新启动。
升级后已经注入旧版 LunaHook 的游戏也需要完全退出一次，以加载新 DLL。

## 字体

Unity 普通 UI 可选择系统字体；TMP 需要匹配版本的字体 AssetBundle，系统字体名不能代替 TMP 资产。
Ren’Py 和 RPG Maker 可导入 TTF/OTF。Unreal 使用游戏已加载的 Font 资源，不把普通字体文件直接当作 Unreal 资源。
“沿用已有 XUnity 字体”和“恢复游戏原字体”是不同选项。安装、替换或卸载前请查看备份及冲突提示。

## 用户数据与更新

API Key 和额外鉴权头通过 Windows DPAPI 保护，保存在自己的 `data/settings.json` 中。
本机服务默认监听 `127.0.0.1:17865`。上游 API Key 不传入游戏插件或 Hook 工作程序。
不要把自己运行后的 `data`、日志、备份、译文或服务配置放进公开仓库。

本地更新功能支持专用更新 ZIP，并提供备份和失败回滚。本仓库随附的是完整 0.7.4 程序目录，
不是专用更新 ZIP，不能通过“本地更新”导入完整程序目录。
迁移旧安装时请先备份数据、关闭工具及游戏，并按使用说明保留恢复所需文件。

## 排查问题

- 没有译文：检查翻译开关、当前服务、模型、游戏适配状态及对白通道。
- API 请求失败：检查接口地址、模型、限流和可选参数。
- 中文缺字：检查字体字形覆盖、TMP 资产版本及具体游戏的绘字方式。
- 安装或恢复出现冲突：保留现有文件，查看安装清单和日志，不覆盖未知修改。
